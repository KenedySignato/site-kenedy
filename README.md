# Site Kenedy Signato

Site: https://kenedysignato.com.br

Página única em HTML, CSS e JS puros, publicada pelo GitHub Pages.

- `index.html`, `styles.css`, `script.js`: o site
- `assets/img/`: imagens em WebP (trabalho, timeline, pessoas, marcas)
- `assets/fonts/`: fonte Archivo variável (licença OFL), hospedada no próprio site
- `.github/scripts/check-links.mjs`: confere se todo arquivo referenciado existe (`node .github/scripts/check-links.mjs`)
